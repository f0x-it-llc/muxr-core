Muxr

Attach to your remote zellij and herdr sessions from your iPhone, iPad or Android device.

Muxr attaches to your zellij and herdr sessions, with full session, tab and pane control and touch-native gestures. That includes the sessions where your coding agents (Claude Code, Codex and others) run, so you can watch and steer them from your phone.

what you get
// features

Built for remote terminal control

Everything you need to drive a herdr or zellij server from a touch device, secured and self-hosted. The server and the app are source available under PolyForm Shield 1.0.0.

TLS + bearer auth

Every connection is encrypted and authenticated. The gRPC boundary speaks the muxr.v1 protobuf contract over TLS with bearer-token auth; a self-signed server's certificate is pinned at pairing.

QR-code device pairing

Pair from the setup TUI by scanning a QR. For a self-signed server the code pins the certificate fingerprint; for a CA-signed server the app uses system trust.

Full session, tab & pane control

Create, rename, and close sessions, tabs, and panes — or switch spaces on herdr. Drive the whole multiplexer, not just a single attached pane.

Touch-native gestures

Tap to focus, tap again for the keyboard, double-tap a pane to toggle its fullscreen, long-press text to select it, swipe back to peel immersive layers. A modifier key bar covers Ctrl, Alt, Esc, arrows.

Tablet split-pane rail

On tablets a persistent 220 px pane rail lists tabs and panes alongside the terminal — collapsing to a 56 px icon mini-rail in immersive mode.

Read-only tokens & biometrics

Mint per-device tokens, read-only or read-write — mutating RPCs fail closed on read-only. Saved credentials are gated behind a biometric unlock for one-tap reconnect.

coding agents
// coding agents

Can I check on my coding agents from my phone?

Yes. Run your coding agent, such as Claude Code or Codex, inside zellij or herdr on your own machine, then attach to that session from Muxr and see its real terminal.

On herdr, an agents list shows which agents are blocked, done, working or idle, most urgent first. On zellij the agent appears as a terminal like any other pane, because zellij reports no agents. Muxr does not integrate with any specific agent: it shows the terminal the agent runs in. Push notifications are coming soon.

how it works
// three steps

From bare server to pocket terminal

Self-host the source available backend, pair once, and you are driving herdr or zellij from anywhere on your network.

01
Run the server
Build or Docker-run muxrd next to your herdr or zellij install — it auto-detects whichever is present. It binds 127.0.0.1:50051 by default — put the machine on your tailnet and bind its Tailscale address in the setup wizard.
02
Pair with a QR code
Open the muxrctl setup wizard, mint a token, and scan the QR it shows. The code encodes the host, port and token; for a self-signed server it also pins the certificate fingerprint, and for a CA-signed server it uses system trust — no further prompts.
03
Control from your phone
Attach to any session and drive tabs, panes, and the keyboard. A biometric prompt offers to save the credential for one-tap reconnect later.

Common questions

What is Muxr?

Muxr is a mobile app for iPhone, iPad and Android phones and tablets that attaches to remote zellij and herdr terminal-multiplexer sessions. It talks to muxrd, a daemon you run on your own machine next to zellij or herdr. More about Muxr

Does Muxr support tmux?

tmux support is coming soon. It is not available today. See the roadmap.

How much does Muxr cost?

Muxr is free to download, and the free app is the full app with one server. Muxr Pro is a one-time $19.99 purchase, 50% off ($9.99) until January 13, 2027. Pricing

Does my traffic go through your servers?

No. Terminal traffic goes from the phone to your own server and does not pass through any server run by F0X IT LLC. Privacy

Is Muxr related to trymuxr or the @trymuxr/cli npm package?

Muxr by F0X IT LLC (muxr.app) is a zellij and herdr client and is unrelated to the npm package @trymuxr/cli at trymuxr.com.
