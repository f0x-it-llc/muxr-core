Does Muxr support tmux? Roadmap and status

Last updated: 15 November 2026

Muxr works with zellij and herdr today. tmux support, push notifications, voice input and desktop apps are coming soon and have not been released yet.

What Muxr supports today and what is coming soon
FeatureStatusNotes
zellijShippedBuilt against zellij 0.45.1.
herdrShippedWorks with the herdr 0.9.x server (0.9.0 to 0.9.5). herdr-core is not supported.

Does Muxr support tmux?

Not yet. tmux support is coming soon, and Muxr does nothing without zellij or herdr. If you use tmux, an SSH terminal with tmux and push support, such as the ones on the comparison page, is the better choice right now.

Does Muxr send push notifications?

Not yet. Push notifications are coming soon. If you want your phone to tell you when an agent needs you, an SSH terminal with tmux and push support, such as the ones on the comparison page, is the better choice right now.

Is there a desktop app?

Not yet. Desktop apps for macOS, Linux and Windows are coming soon. Today Muxr runs on iPhone, iPad and Android phones and tablets, and the server runs on Linux and Apple Silicon macOS. Windows is not supported for the server, which needs a Unix host. Until a desktop app is released, use the phone or tablet app.

Does Muxr have voice input?

Not yet. Voice input is coming soon. Today you type with the on-screen keyboard and the key bar, which has Ctrl, Alt, Esc and the arrow keys.

How do I hear when something ships?

Watch the releases page of f0x-it-llc/muxr-core on GitHub, and read the release notes in the App Store and Google Play listings. This page lists no dates, because none have been announced.
