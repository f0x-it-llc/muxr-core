Muxr vs the zellij web client

Last updated: 15 November 2026. Published by the makers of Muxr.

The zellij web client is part of zellij and free: you start it with zellij web and attach from a browser, with no app and no extra daemon, while Muxr is a native app that talks to its own server, muxrd. The web client suits occasional access and anyone who wants nothing extra installed; Muxr suits daily use from a phone or tablet and people who also run herdr.

The short answer

Pick the zellij web client if you want zellij on a phone with no app and no extra daemon, or need only occasional access. For occasional access, the web client is enough.

Pick Muxr if you want a native app with gestures and a key bar, QR pairing, per-device tokens, herdr support or a tablet pane rail.

What does the zellij web client need?

The web client is off by default; you start it with zellij web. It lets you attach to existing sessions, or start new ones, from a browser. HTTPS is required when it listens on anything other than 127.0.0.1, and login tokens are required. Read-only tokens exist. It has no built-in rate limiting, so a reverse proxy is recommended.

On phones it detects mobile browsers and offers touch scrolling, on-screen keys, pane and tab pickers and single-pane fullscreen, and it can be installed as a web app.

Where is the zellij web client the better choice?

  • Nothing goes on the phone and no extra daemon goes on the server: zellij already includes it.
  • It is free, because it ships with zellij.
  • For occasional access it is enough: start zellij web, open a browser, sign in with a login token and attach.
  • It has read-only tokens too, and its phone mode has on-screen keys and pane and tab pickers.

Where is Muxr the better choice?

  • A native app. Tap a pane to focus it, tap again for the keyboard, and use the key bar for Ctrl, Alt, Esc and the arrows.
  • QR pairing and per-device tokens. You scan a code shown by muxrctl that carries host, port and token; for a self-signed server it also pins the certificate fingerprint. Each phone gets its own token, which you mint and revoke in muxrctl.
  • herdr. Muxr works with the herdr 0.9.x server (0.9.0 to 0.9.5) and lists the coding agents herdr reports. herdr-core is not supported.
  • Tablets. A persistent pane rail sits beside the terminal.
