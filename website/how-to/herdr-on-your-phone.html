How to use herdr from your phone or tablet

Last updated: 15 November 2026

You can reach herdr sessions from a phone with the herdr project's own mobile app, with Muxr, or with a community client. Which one fits depends on the herdr server you run. The herdr mobile app says it "works with herdr-core", as published on 15 November 2026.

Muxr works with the herdr 0.9.x server (0.9.0 to 0.9.5). herdr-core is not supported.

The herdr mobile app is free, made by the herdr project, and connects over SSH with no herdr account and no server of the project's in between. Its page also says "Herdr TUI isn't supported". If you run herdr-core, it is the better pick. Muxr is described below.

Which herdr does Muxr work with?

Muxr works with the herdr 0.9.x server (0.9.0 to 0.9.5). herdr-core is not supported.

The Muxr server, muxrd, drives a herdr binary that you install yourself, over herdr's public Unix sockets. Version 0.9.0 is the supported floor and 0.9.5 is the newest release tested. muxrd also works with zellij and detects whichever of the two is installed.

How do I set it up?

  1. Install the Muxr app from the App Store or Google Play.
  2. On the machine that runs herdr, install the server: 
    curl -fsSL https://raw.githubusercontent.com/f0x-it-llc/muxr-core/main/install.sh | bash
  3. Install Tailscale on the server and on your phone and sign both into the same tailnet. A LAN address or a public domain also work.
  4. Run muxrctl on the server. Its setup wizard opens on first run, and muxrd finds herdr by itself.
  5. In the app, tap the QR scan button on the Connect screen and scan the code that muxrctl shows.

The full walk-through, with screenshots, is the quick start.

What can I do once connected?

You can browse, open, create, rename and close spaces, tabs and panes, and type into a pane with a key bar for Ctrl, Alt, Esc and the arrows. Muxr shows the terminal that your agent runs in. It does not integrate with any specific agent.

On herdr, the agents list shows the coding agents running in a session, most urgent first: blocked, then done, working and idle, with a count for each.

For a watch-only device, create a read-only token in muxrctl. A read-only token can navigate tabs, panes and spaces and scroll, but it cannot type or change the session.

Will my phone alert me when an agent is blocked?

Not yet. Push notifications are Coming soon in Muxr, and the app does not deliver notifications today.

If alerts are the main thing you need, pick a client that offers them now. According to their own pages, Collie sends push when an agent pauses or finishes, Sherpr gives on-device notifications, and Whip and herdrup offer push through a relay. The table below links each source.
