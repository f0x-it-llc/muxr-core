Run Claude Code or Codex from your phone with zellij

Last updated: 15 November 2026

A coding agent that runs in a terminal keeps running inside a zellij or herdr session on your computer, and any phone client that can attach to that session lets you watch it and type to it. Muxr does this for zellij and herdr, and the vendors' own remote features do it without a terminal.

What are my options?

Four ways to reach a coding agent from a phone, as published on 15 November 2026. Muxr is one of them, and it is not the right pick for everyone.

Ways to control a coding agent from your phone
Option What you see Where traffic goes What you need Notifications
Claude Code Remote Control The conversation, in claude.ai/code or the Claude iOS and Android apps. A terminal emulator is not described. The local session makes outbound HTTPS requests only; traffic goes through the Anthropic API, and the transcript is stored on Anthropic's servers while connected. A paid Claude plan (API keys are not supported). The computer must stay on with claude running. Claude Code only. Not stated
Codex remote connections in the ChatGPT app Threads, approvals, diffs and terminal output. An interactive terminal: not stated. Through "a secure relay layer". The ChatGPT app on iOS or Android and a Codex host, the ChatGPT desktop app on macOS or Windows. Plans required: not stated. Not stated
An SSH app with tmux or zellij A real terminal: the ordinary zellij interface, drawn at the phone's screen size and driven by zellij's keyboard shortcuts. SSH to your own machine. Any SSH client, such as Termius or Blink Shell, and an SSH server on the machine. Not stated
Muxr with zellij or herdr A real terminal. On herdr, also a list of agents. gRPC over TLS from the phone to your own server. No SSH, and nothing passes through a server run by F0X IT LLC. Muxr on the phone, and muxrd on the computer next to zellij or herdr. Push notifications Coming soon

When is the built-in remote feature the better choice?

When you use one vendor's agent, want notifications and do not need the terminal. If you use Claude Code alone, Remote Control is the better pick: you get Anthropic's own notifications with nothing to self-host. The same reasoning applies to Codex remote connections if Codex is the one agent you run.

Muxr makes more sense when you want the real terminal, run more than one agent, or want the traffic to stay between your phone and your own machine. A longer comparison is on Muxr and Claude Code Remote Control.

How do I set this up with Muxr?

  1. On the computer, start a named zellij session, or a herdr session, that you will recognise later.
  2. Run the agent inside it, in a pane, as you would in any terminal.
  3. Install the server on the same computer. It installs muxrd and muxrctl: 
    curl -fsSL https://raw.githubusercontent.com/f0x-it-llc/muxr-core/main/install.sh | bash
  4. Run muxrctl, follow the setup wizard and scan the pairing QR code from the Muxr app on your phone. The quick start has every step, including reaching the server over a tailnet such as Tailscale.
  5. Open the session from the app's Sessions screen and open the agent's pane.
  6. Close the app when you are done. The session keeps running on your computer, and the agent keeps working in it.

The app is free with one server. Muxr Pro is a one-time $19.99 purchase, 50% off ($9.99) until January 13, 2027.

What does Muxr show about my agents?

On herdr, Muxr lists the coding agents running in a session, most urgent first: blocked, then done, working, idle, with counts. Which agents herdr reports is up to herdr.

On zellij there is no agents list, because zellij reports no agents. The agent's pane is a terminal like any other pane. Muxr does not tie in with any specific agent: it shows the terminal the agent runs in.

Will I get a notification when the agent needs me?

Not yet. Push notifications are Coming soon; the app does not deliver notifications today. See the roadmap. If notifications matter to you now, the built-in remote features above are the better choice.

Can someone else watch without being able to type?

Yes. A read-only token can navigate tabs, panes and spaces, scroll, and resize its own terminal, but cannot type or change the session. Tick Read-only when you name the token in muxrctl, then pair the other person's phone with it.
