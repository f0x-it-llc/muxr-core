How to use zellij on iPhone and iPad

Last updated: 15 November 2026

You can attach to a zellij session running on a Linux or Mac machine from an iPhone or iPad in three ways: Muxr, zellij's own web client in a browser, or an SSH app running zellij attach. Muxr fits when you want a purpose-built zellij client with panes and tabs; the web client fits when you want no app, and an SSH app fits when you cannot install anything on the server.

What do I need?

  • A Linux or Mac machine running zellij (or herdr), with a session you want to reach. The server, muxrd, works with zellij 0.45.1 and 0.46.0 and refuses other versions. Windows is not supported for the server.
  • The Muxr app on your iPhone or iPad, which needs iOS 15.0 or iPadOS 15.0 or later.
  • A network path from the phone to the machine. A tailnet such as Tailscale is the recommended one; a LAN address or a public domain also work.

How do I set it up with Muxr?

The quick start has the full walkthrough with screenshots. In short:

  1. Install Muxr from the App Store.
  2. On the machine that runs zellij, install the server, muxrd, and its setup TUI, muxrctl: 
    curl -fsSL https://raw.githubusercontent.com/f0x-it-llc/muxr-core/main/install.sh | bash
  3. Install Tailscale on the machine and on your phone, and sign both into the same tailnet.
  4. Run muxrctl on the machine. The setup wizard opens on first run and ends with a QR code.
  5. In the app, tap the QR scan button on the Connect screen and point the camera at the code. Scan before you press Done, because the token secret is shown once.

Your sessions appear in the app. The free app is the full app with one server. Muxr Pro is a one-time $19.99 purchase, 50% off ($9.99) until January 13, 2027.

What is different on an iPad?

On a tablet, the app shows a persistent pane rail beside the terminal instead of the phone's floating button and bottom sheet. The rail lists your tabs and panes, so you can switch between them while the terminal stays on screen. In immersive mode it collapses to a narrow icon rail.

If you type on a hardware keyboard, Settings has a toggle called mac-option-as-meta that sets how the Option key behaves. The usage guide covers the tablet layout in full.

Can I do this without installing a server daemon?

Yes. Two other routes need nothing from Muxr, and each has trade-offs. Both are described here as published on 15 November 2026.

The zellij web client. It ships with zellij, is off by default and starts with zellij web. According to the zellij documentation, it lets you attach to existing sessions from a browser, requires HTTPS when it listens on anything other than 127.0.0.1, and uses login tokens. On phones it offers touch scrolling, on-screen keys, pane and tab pickers and single-pane fullscreen, and it can be installed as a web app. It has no built-in rate limiting, so the documentation recommends a reverse proxy. It is free and needs no extra daemon, which makes it a good fit for occasional access. See Compare Muxr with the zellij web client.

An SSH app running zellij attach. Any SSH client works, such as Blink Shell, Termius or Prompt 3, and the machine needs just an SSH server. You get the ordinary zellij interface drawn at the phone's screen size, driven by zellij's keyboard shortcuts. This suits you if you already live in an SSH app or cannot install a daemon. See Compare Muxr with SSH and zellij.

Which gestures and keys work?

  • Tap a pane to focus it; tap the focused pane again to open the keyboard.
  • Double-tap a pane to toggle server-side pane fullscreen.
  • Long-press text to select it, then tap the Copy chip.
  • The key bar adds Ctrl and Alt as one-shot latches, plus Esc, Tab, the arrows, PgUp, PgDn and Del.
  • The back gesture leaves immersive mode first, then asks whether to detach.
  • A read-only token disables the key bar and sends nothing to the server.

The full list is in the usage guide.

What if it does not connect?

  • Pairing fails or the QR will not scan: check that muxrd is running and reachable, then see the support FAQ.
  • Connection refused or timed out: the server binds 127.0.0.1 by default, so a phone needs a tailnet or LAN bind address; see the support FAQ.
  • Still stuck: write to support and include the details listed under before you write in.
