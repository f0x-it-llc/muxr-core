Muxr FAQ: zellij and herdr on your phone

Last updated: 15 November 2026

Muxr is a mobile app that attaches to zellij and herdr sessions on your own machine, with a daemon called muxrd on that machine. These short answers cover what it works with, how it connects, what it costs and how it differs from other apps.

What is Muxr, in short?

What is Muxr?

Muxr is a mobile app for iPhone, iPad and Android phones and tablets that attaches to remote zellij and herdr terminal-multiplexer sessions. It talks to muxrd, a daemon you run on your own machine next to zellij or herdr. More about Muxr

Who makes Muxr?

Muxr is published by F0X IT LLC. It is source available: the server is on GitHub and the app is on GitHub too.

Is Muxr related to trymuxr or the @trymuxr/cli npm package?

Muxr by F0X IT LLC (muxr.app) is a zellij and herdr client and is unrelated to the npm package @trymuxr/cli at trymuxr.com.

Which phones and tablets does Muxr run on, and which OS versions?

Muxr runs on iPhone and iPad with iOS 15.0 or iPadOS 15.0 or later, and on Android phones and tablets with Android 10 or later. Get it from the App Store or Google Play.

Is there a desktop app?

Desktop apps for macOS, Linux and Windows are coming soon. See the roadmap.

What does Muxr work with?

Does Muxr work with zellij?

Yes. muxrd is built against zellij 0.45.1. The how-to guides cover iPhone and iPad and Android.

Does Muxr work with herdr, and which herdr?

Yes. Muxr works with the herdr 0.9.x server (0.9.0 to 0.9.5). herdr-core is not supported. Muxr and herdr on your phone

Does Muxr support tmux?

tmux support is coming soon. It is not available today. See the roadmap.

Can I use Muxr without zellij or herdr?

No. Without zellij or herdr on the server Muxr does nothing, because it is not a general SSH client. The server detects whichever of the two is installed.

Which servers can run muxrd: Linux, macOS or Windows?

Pre-built binaries exist for x86_64 Linux, aarch64 Linux and Apple Silicon macOS. Intel Macs build from source. Windows is not supported, because the server needs a Unix host.

Can I use Muxr with coding agents?

Can I use Muxr to check on Claude Code or Codex from my phone?

Yes, as a terminal. Muxr does not integrate with any specific agent; it shows the terminal the agent runs in. Claude Code and Codex on your phone

What does the agents list show, and on which backend?

On herdr, Muxr lists the coding agents running in a session, most urgent first (blocked, then done, working, idle), with counts. On zellij there is no agents list, because zellij reports no agents; an agent running in a zellij pane appears as a terminal like any other pane.

Does Muxr notify me when an agent needs input?

Not today. Push notifications are coming soon, and the app does not deliver notifications yet. See the roadmap.

How is Muxr different from Claude Code Remote Control?

As published on 15 November 2026, Claude Code Remote Control continues a local Claude Code session from claude.ai/code or the Claude apps, works with Claude Code only and sends traffic through the Anthropic API. Muxr shows the terminal itself, and terminal traffic goes from your phone to your own server. Compare in detail

How do I set up and connect Muxr?

How do I connect my phone to my server?

Install muxrd on the server, run muxrctl, and scan the QR code it shows from the Muxr app. Quick start

Do I need Tailscale or a VPN?

No, but a tailnet such as Tailscale is the recommended way to reach the server from a phone. A LAN address or a public domain are the alternatives. Advanced setup

Does Muxr use SSH?

No. The app talks to muxrd over gRPC protected by TLS, signed in with a per-device bearer token.

Can I reach my server away from home?

Yes, over a tailnet, which follows the phone onto mobile data. A LAN address works on that LAN alone. LAN, tailnet and public domain

Do I need to open a port?

With a tailnet you bind muxrd to the server's tailnet address on port 50051, as the quick start shows. The default address, 127.0.0.1:50051, is unreachable from a phone. A public domain exposes muxrd to the open internet and is the least recommended route. Advanced setup

Is there a demo server?

A public read-only demo server runs at demo.muxr.app.

Can I connect to more than one server?

Yes, with Muxr Pro. The free app is the full app with one server. Pricing

What does Muxr cost, and what is the licence?

How much does Muxr cost?

Muxr is free to download, and the free app is the full app with one server. Muxr Pro is a one-time $19.99 purchase, 50% off ($9.99) until January 13, 2027. Pricing

Is there a subscription?

No. Muxr Pro is a one-time purchase, made through the App Store or Google Play, and it belongs to that store account.

What does the free version include?

The free app is the full app with one server. The muxrd server is free to use under its licence, and you host it yourself.

What does Pro add?

Pro unlocks more than one server, with saved servers you can switch between.

Is Muxr source available, and under which licences?

Muxr is source available. The server, muxr-core, and the app, muxr-app, are both under the PolyForm Shield License 1.0.0. It lets you use, modify and share them for any purpose, except to provide a product that competes with Muxr.

Can I use Muxr at work?

Yes. Both the app and the server are free to use at work under the PolyForm Shield License 1.0.0. The one limit is that you may not use them to provide a product that competes with Muxr.

Is Muxr secure and private?

How does Muxr protect my connection?

The app talks to muxrd over TLS with a per-device bearer token. A QR code for a self-signed server also pins the certificate fingerprint. Security

Does my traffic go through your servers?

No. Terminal traffic goes from the phone to your own server and does not pass through any server run by F0X IT LLC. Privacy

Do I need an account?

No. Muxr has no account.

What does a read-only token allow?

A read-only token can navigate tabs, panes and spaces, scroll, and resize its own terminal. It cannot type or change the session.

Does the app collect analytics?

No. Muxr has no analytics, no ads and no crash reporting.

How are saved credentials protected?

Saved credentials are kept in the iOS Keychain or the Android Keystore, gated behind device biometrics.

How does Muxr compare with other apps?

How is Muxr different from Moshi?

As published on 15 November 2026, Moshi connects by SSH, Mosh or Eternal Terminal and needs no server install, while Muxr needs muxrd and uses no SSH. In our judgement Moshi is the better pick if you need tmux today, push notifications, voice input or Apple Watch. Compare in detail

How is Muxr different from Termius or Blink Shell?

As published on 15 November 2026, Termius is a general SSH client for desktop and mobile, and Blink Shell is a terminal for iOS with SSH and Mosh. Muxr is not a general SSH client and attaches to zellij and herdr sessions. Read the Termius comparison or the Blink Shell comparison.

How is Muxr different from zellij's own web client?

As published on 15 November 2026, the zellij web client is part of zellij, runs in a browser and is started with zellij web. In our judgement it is the better pick if you want zellij on a phone with no app and no extra daemon; it does not attach to herdr. Compare in detail

How is Muxr different from the Herdr mobile app?

As published on 15 November 2026, the Herdr mobile app is free, made by the herdr project and connects over SSH to herdr-core. Muxr works with the herdr 0.9.x server, not herdr-core, and also works with zellij. In our judgement the Herdr mobile app is the better pick if you run herdr-core. Compare in detail

What if something goes wrong?

What if pairing fails or the QR code will not scan?

Check that muxrd is running, that the phone can reach the server and that the token has not been revoked. If the camera cannot read the code, enter the server address and token by hand on the Connect screen. Support: pairing fails

What does a TLS fingerprint mismatch mean?

The certificate the server presents no longer matches the fingerprint the app pinned, usually because the self-signed certificate was regenerated. If the change was intentional, remove the saved server in the app and pair again by QR. Support: TLS fingerprint mismatch

What if the connection is refused?

muxrd binds 127.0.0.1:50051 by default, which accepts connections from the same machine alone. Bind an address the phone can reach, list it in the certificate and check your firewall. Support: connection refused
